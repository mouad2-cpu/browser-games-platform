# Projet Gestion de Production et Supply Chain Management

Livrable personnalisé pour **Jorf Moaad**, filière **Systèmes Automatisés et
Intelligence Artificielle pour l’Industrie 4.0**.

## Fichiers

- `Jorf_Moaad_Projet_Gestion_Production_Supply_Chain.pdf` : rapport final à remettre.
- `rapport.html` : source éditable du rapport.
- `generer-pdf.sh` : génération reproductible du PDF avec Chromium.

## Régénération

```bash
chmod +x generer-pdf.sh
./generer-pdf.sh
```

Un chemin de sortie personnalisé peut être fourni en premier argument :

```bash
./generer-pdf.sh /tmp/rapport.pdf
```

Le rapport répond aux trois parties de l’énoncé, explicite les hypothèses de
calcul et inclut les tableaux, graphiques, matrices et recommandations demandés.
