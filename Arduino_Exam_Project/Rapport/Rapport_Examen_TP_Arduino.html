Introduction

Ce travail pratique porte sur la programmation d'une carte Arduino Uno et sur la vérification de son fonctionnement dans Proteus ISIS. Les quatre exercices abordent des situations simples d'instrumentation : lire une grandeur analogique, commander des sorties numériques avec une temporisation, lire un bouton-poussoir et positionner un servomoteur.

Les programmes sont écrits et compilés dans Arduino IDE. Le fichier HEX obtenu est ensuite chargé dans le composant Arduino Uno du schéma Proteus. Cette méthode permet d'observer le comportement du montage avant une éventuelle réalisation physique.

Les objectifs du TP sont les suivants :

  • utiliser les entrées analogiques et numériques de l'Arduino ;
  • piloter des LED en respectant un état et une durée imposés ;
  • comprendre le rôle d'une résistance pull-down ;
  • convertir une mesure analogique en consigne angulaire avec map() ;
  • vérifier la cohérence entre le câblage, le programme et les résultats.
Note avant remise : les cadres marqués « À insérer » et « À compléter » doivent être remplacés par les captures et observations obtenues réellement dans Proteus. Ce document ne prétend pas qu'une simulation a été exécutée.

Exercice 1 — Détecteur de seuil analogique

Objectif : allumer une LED rouge uniquement lorsque la valeur mesurée sur l'entrée A0 est strictement supérieure à 512.

1. Composants et connexions

Le montage utilise un Arduino Uno R3, un potentiomètre POT-HG, une LED rouge et une résistance MINIRES de 220 Ω pour limiter le courant de la LED.

ÉlémentConnexion Proteus
PotentiomètreBornes extérieures vers 5 V et GND ; curseur vers A0
LED rougeBroche 8 → résistance 220 Ω → anode ; cathode → GND

2. Schéma électrique

Capture du schéma Proteus à insérer ici
La capture doit montrer l'Arduino Uno, A0, la broche 8, le potentiomètre, la LED, la résistance, le 5 V et le GND.

3. Programme Arduino commenté

const int potentiometerPin = A0;
const int ledPin = 8;

void setup() {
  // La LED est commandée par la broche 8.
  pinMode(ledPin, OUTPUT);
}

void loop() {
  // Lecture du potentiomètre entre 0 et 1023.
  int analogValue = analogRead(potentiometerPin);

  // La LED s'allume seulement au-dessus du seuil 512.
  if (analogValue > 512) {
    digitalWrite(ledPin, HIGH);
  } else {
    digitalWrite(ledPin, LOW);
  }
}

4. Fonctionnement du programme

La fonction analogRead(A0) produit une valeur entière comprise entre 0 et 1023. À chaque passage dans loop(), le programme compare cette mesure au seuil 512. Si la condition analogValue > 512 est vraie, la sortie 8 passe à l'état HIGH et la LED s'allume. Sinon, la sortie reste à LOW et la LED s'éteint. La valeur 512 elle-même appartient donc au cas « LED éteinte ».

5. Résultats attendus

  • mesure comprise entre 0 et 512 : LED éteinte ;
  • mesure comprise entre 513 et 1023 : LED allumée ;
  • le changement d'état se produit au franchissement du seuil.

Exercice 2 — Gestion d'un feu tricolore

Objectif : reproduire en boucle un cycle de signalisation composé de 3 s de vert, 1 s de jaune et 3 s de rouge.

1. Composants et connexions

Le montage contient un Arduino Uno R3, une LED rouge, une LED jaune, une LED verte et trois résistances MINIRES de 220 Ω.

FeuSortie ArduinoConnexion
Rouge13D13 → 220 Ω → anode ; cathode → GND
Jaune12D12 → 220 Ω → anode ; cathode → GND
Vert11D11 → 220 Ω → anode ; cathode → GND

2. Schéma électrique

Capture du schéma Proteus à insérer ici
La capture doit rendre lisibles les broches 13, 12 et 11, les trois LED, leurs résistances et le GND commun.

3. Programme Arduino commenté

const int redLedPin = 13;
const int yellowLedPin = 12;
const int greenLedPin = 11;

void setup() {
  pinMode(redLedPin, OUTPUT);
  pinMode(yellowLedPin, OUTPUT);
  pinMode(greenLedPin, OUTPUT);
}

void loop() {
  // Feu vert pendant 3 secondes.
  digitalWrite(greenLedPin, HIGH);
  digitalWrite(yellowLedPin, LOW);
  digitalWrite(redLedPin, LOW);
  delay(3000);

  // Feu jaune pendant 1 seconde.
  digitalWrite(greenLedPin, LOW);
  digitalWrite(yellowLedPin, HIGH);
  digitalWrite(redLedPin, LOW);
  delay(1000);

  // Feu rouge pendant 3 secondes.
  digitalWrite(greenLedPin, LOW);
  digitalWrite(yellowLedPin, LOW);
  digitalWrite(redLedPin, HIGH);
  delay(3000);
}

4. Fonctionnement du programme

Les trois broches sont configurées comme sorties. Pour chaque phase, le programme place une seule sortie à HIGH et force les deux autres à LOW. delay(3000) maintient le vert ou le rouge pendant 3000 ms, tandis que delay(1000) maintient le jaune pendant 1000 ms. À la fin de loop(), Arduino recommence automatiquement au feu vert. Un cycle complet dure 7 secondes.

5. Résultats attendus

0 à 3 sAlluméÉteintÉteint
3 à 4 sÉteintAlluméÉteint
4 à 7 sÉteintÉteintAllumé
Le cycle reprend ensuite sans arrêt et deux couleurs ne doivent jamais rester allumées simultanément.

Exercice 3 — Commande manuelle d'éclairage

Objectif : allumer une LED bleue uniquement pendant le maintien du bouton-poussoir.

1. Composants et connexions

Le montage emploie un Arduino Uno R3, un bouton BUTTON, une LED bleue, une résistance MINIRES de 10 kΩ pour le pull-down et une résistance MINIRES de 220 Ω pour limiter le courant de la LED.

ÉlémentConnexion Proteus
BoutonUne borne vers 5 V ; l'autre vers la broche 2
Pull-downRésistance 10 kΩ entre la broche 2 et GND
LED bleueBroche 7 → résistance 220 Ω → anode ; cathode → GND

2. Schéma électrique

Capture du schéma Proteus à insérer ici
Montrer clairement le 5 V, le bouton, la broche 2, la résistance pull-down de 10 kΩ vers GND, ainsi que la LED sur la broche 7.

3. Programme Arduino commenté

const int buttonPin = 2;
const int ledPin = 7;

void setup() {
  // Le bouton utilise une résistance pull-down externe de 10 kΩ.
  pinMode(buttonPin, INPUT);
  pinMode(ledPin, OUTPUT);
}

void loop() {
  // La lecture vaut HIGH uniquement pendant l'appui.
  int buttonState = digitalRead(buttonPin);

  if (buttonState == HIGH) {
    digitalWrite(ledPin, HIGH);
  } else {
    digitalWrite(ledPin, LOW);
  }
}

4. Fonctionnement du programme

Lorsque le bouton est relâché, la résistance de 10 kΩ relie l'entrée 2 au GND. digitalRead(2) renvoie alors LOW et la LED est éteinte. Pendant l'appui, le bouton relie l'entrée au 5 V : la lecture devient HIGH et le programme allume la sortie 7. L'utilisation de INPUT est volontaire, car le pull-down demandé est une résistance externe. Aucun état n'est mémorisé après le relâchement.

État du boutonNiveau sur D2LED bleue

Maintenu enfoncéHIGHAllumée

Exercice 4 — Contrôle angulaire d'un servomoteur

Objectif : convertir la valeur 0–1023 d'un potentiomètre en un angle 0–180° avec map(), puis transmettre cette consigne au servomoteur raccordé à la broche 9.

1. Composants et connexions

Le montage comprend un Arduino Uno R3, un potentiomètre POT-HG et un servomoteur MOTOR-SERVO.

ÉlémentConnexion Proteus
PotentiomètreBornes extérieures vers 5 V et GND ; curseur vers A0
Signal du servomoteurBroche PWM 9
Alimentation du servomoteurVCC vers 5 V ; GND vers la masse commune

Pour une réalisation physique, un servomoteur peut nécessiter une alimentation 5 V externe capable de fournir le courant demandé. La masse de cette alimentation doit rester commune avec le GND de l'Arduino.

2. Schéma électrique

Capture du schéma Proteus à insérer ici
La capture doit montrer A0, la broche PWM 9, le potentiomètre, le servomoteur, le 5 V et le GND commun.

3. Programme Arduino commenté

#include <Servo.h>

const int potentiometerPin = A0;
const int servoPin = 9;

Servo myServo;

void setup() {
  // Association du signal du servomoteur à la broche 9.
  myServo.attach(servoPin);
}

void loop() {
  // Lecture de la position du potentiomètre.
  int analogValue = analogRead(potentiometerPin);

  // Conversion de 0-1023 vers un angle de 0-180 degrés.
  int angle = map(analogValue, 0, 1023, 0, 180);

  // Application de l'angle au servomoteur.
  myServo.write(angle);
}

4. Fonctionnement du programme

La bibliothèque Servo.h produit automatiquement le signal de commande adapté. attach(9) associe l'objet servomoteur à la broche 9. Ensuite, analogRead(A0) mesure la position du potentiomètre. La fonction map(analogValue, 0, 1023, 0, 180) transforme cette mesure en angle. Enfin, write(angle) applique la nouvelle consigne. La boucle recommence continuellement afin de suivre les déplacements du potentiomètre.

Valeur analogiqueAngle théorique

Le déplacement du servomoteur doit suivre la variation du potentiomètre entre les deux positions extrêmes.
