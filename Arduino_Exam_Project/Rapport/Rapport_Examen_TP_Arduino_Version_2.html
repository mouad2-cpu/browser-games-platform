Présentation du travail

Ce TP consiste à développer quatre petites applications autour d'une carte Arduino Uno. Elles sont d'abord programmées dans Arduino IDE, puis prévues pour être testées dans Proteus ISIS après chargement du fichier HEX. Chaque manipulation cible une notion différente : la mesure analogique, les temporisations, l'entrée numérique et la commande d'un servomoteur.

La démarche suivie est la même pour chaque partie. Le montage est câblé conformément au sujet, les broches sont déclarées dans le programme, puis le comportement attendu est comparé aux observations de la simulation. Cette comparaison permet de repérer une erreur de câblage ou de logique.

Objectifs pédagogiques

  • acquérir une valeur avec analogRead() ;
  • utiliser digitalRead() et digitalWrite() ;
  • produire une séquence temporelle avec delay() ;
  • stabiliser une entrée grâce à une résistance pull-down ;
  • commander un servo avec Servo.h et map().

Manipulation 1 — Détection d'un seuil

But : utiliser le potentiomètre comme entrée analogique et commander une LED rouge lorsque la mesure dépasse strictement 512.

Matériel et câblage

Composants Proteus : ARDUINO UNO R3, POT-HG, LED-RED et MINIRES 220 Ω.
Point du circuitRaccordement
Deux extrémités du POT-HGUne au 5 V et l'autre au GND
Curseur du POT-HGEntrée analogique A0
Commande de la LEDD8 → résistance 220 Ω → anode de LED
Retour de la LEDCathode vers GND

Emplacement du schéma

[Insérer la capture Proteus de l'exercice 1]
Les connexions A0, D8, 5 V et GND doivent être lisibles.

Programme employé

const int potentiometerPin = A0;
const int ledPin = 8;

void setup() {
  // La LED est commandée par la broche 8.
  pinMode(ledPin, OUTPUT);
}

void loop() {
  // Lecture du potentiomètre entre 0 et 1023.
  int analogValue = analogRead(potentiometerPin);

  // La LED s'allume seulement au-dessus du seuil 512.
  if (analogValue > 512) {
    digitalWrite(ledPin, HIGH);
  } else {
    digitalWrite(ledPin, LOW);
  }
}

Lecture du fonctionnement

Chaîne logique : position du potentiomètre → conversion analogique sur 10 bits → comparaison à 512 → choix de l'état de D8.

L'entrée A0 fournit un nombre de 0 à 1023. La condition utilise le signe « supérieur à » et non « supérieur ou égal ». Par conséquent, la mesure 512 laisse la LED éteinte ; la première valeur qui l'allume est 513.

Manipulation 2 — Séquence d'un feu tricolore

But : répéter automatiquement l'ordre vert, jaune, rouge avec des durées respectives de 3 s, 1 s et 3 s.

Matériel et câblage

Composants Proteus : ARDUINO UNO R3, LED-GREEN, LED-YELLOW, LED-RED et trois MINIRES 220 Ω.
CouleurBrocheBranchement
RougeD13D13 → 220 Ω → anode ; cathode → GND
JauneD12D12 → 220 Ω → anode ; cathode → GND
VertD11D11 → 220 Ω → anode ; cathode → GND

Emplacement du schéma

[Insérer la capture Proteus de l'exercice 2]
Identifier clairement les trois sorties et les trois résistances.

Programme employé

const int redLedPin = 13;
const int yellowLedPin = 12;
const int greenLedPin = 11;

void setup() {
  pinMode(redLedPin, OUTPUT);
  pinMode(yellowLedPin, OUTPUT);
  pinMode(greenLedPin, OUTPUT);
}

void loop() {
  // Feu vert pendant 3 secondes.
  digitalWrite(greenLedPin, HIGH);
  digitalWrite(yellowLedPin, LOW);
  digitalWrite(redLedPin, LOW);
  delay(3000);

  // Feu jaune pendant 1 seconde.
  digitalWrite(greenLedPin, LOW);
  digitalWrite(yellowLedPin, HIGH);
  digitalWrite(redLedPin, LOW);
  delay(1000);

  // Feu rouge pendant 3 secondes.
  digitalWrite(greenLedPin, LOW);
  digitalWrite(yellowLedPin, LOW);
  digitalWrite(redLedPin, HIGH);
  delay(3000);
}

Lecture du fonctionnement

Séquence : VERT/HIGH pendant 3000 ms → JAUNE/HIGH pendant 1000 ms → ROUGE/HIGH pendant 3000 ms → retour au début de loop().

Chaque étape allume une couleur et force les deux autres à LOW. Cette écriture explicite empêche le maintien accidentel de deux feux. La fonction delay() conserve l'état pendant la durée demandée. La période du cycle complet vaut 7 secondes.

Manipulation 3 — Éclairage commandé par bouton

But : obtenir une action non maintenue : la LED bleue est active pendant l'appui et s'éteint dès que le bouton est relâché.

Matériel et câblage

Composants Proteus : ARDUINO UNO R3, BUTTON, LED-BLUE, une MINIRES 10 kΩ et une MINIRES 220 Ω.
ÉlémentRaccordement
BoutonEntre le 5 V et l'entrée D2
Pull-down10 kΩ entre D2 et GND
LED bleueD7 → 220 Ω → anode ; cathode → GND

Emplacement du schéma

[Insérer la capture Proteus de l'exercice 3]
Faire apparaître la résistance 10 kΩ entre D2 et la masse.

Programme employé

const int buttonPin = 2;
const int ledPin = 7;

void setup() {
  // Le bouton utilise une résistance pull-down externe de 10 kΩ.
  pinMode(buttonPin, INPUT);
  pinMode(ledPin, OUTPUT);
}

void loop() {
  // La lecture vaut HIGH uniquement pendant l'appui.
  int buttonState = digitalRead(buttonPin);

  if (buttonState == HIGH) {
    digitalWrite(ledPin, HIGH);
  } else {
    digitalWrite(ledPin, LOW);
  }
}

Lecture du fonctionnement

Au repos : la résistance impose 0 V sur D2, donc LOW et LED éteinte.
Pendant l'appui : le bouton applique 5 V sur D2, donc HIGH et LED allumée.

La broche 2 est déclarée en INPUT, car le montage contient déjà une résistance de rappel externe. Le programme recopie le sens logique du bouton sur la LED sans mémoriser l'état précédent.

Manipulation 4 — Positionnement d'un servomoteur

But : faire correspondre la course 0–1023 du potentiomètre à une consigne angulaire allant de 0° à 180°.

Matériel et câblage

Composants Proteus : ARDUINO UNO R3, POT-HG et MOTOR-SERVO.
ÉlémentRaccordement
PotentiomètreExtrémités au 5 V et GND ; curseur sur A0
Signal du servoBroche PWM D9
Alimentation du servoVCC au 5 V et masse au GND commun

En montage réel, une alimentation 5 V séparée peut être nécessaire pour le courant du servomoteur. Sa masse doit être commune avec celle de l'Arduino.

Emplacement du schéma

[Insérer la capture Proteus de l'exercice 4]
Montrer A0, D9, les alimentations et la masse commune.

Programme employé

#include <Servo.h>

const int potentiometerPin = A0;
const int servoPin = 9;

Servo myServo;

void setup() {
  // Association du signal du servomoteur à la broche 9.
  myServo.attach(servoPin);
}

void loop() {
  // Lecture de la position du potentiomètre.
  int analogValue = analogRead(potentiometerPin);

  // Conversion de 0-1023 vers un angle de 0-180 degrés.
  int angle = map(analogValue, 0, 1023, 0, 180);

  // Application de l'angle au servomoteur.
  myServo.write(angle);
}

Lecture du fonctionnement

Traitement : mesure A0 → map() vers 0–180 → myServo.write(angle) → nouvelle position du servo.

L'objet myServo est lié à D9 par attach(). Dans la boucle, la conversion conserve les deux extrêmes : une lecture nulle donne 0°, tandis que 1023 donne 180°. Une lecture proche du milieu fournit un angle proche de 90°.

Synthèse finale

Ce TP réunit quatre usages fondamentaux de l'Arduino Uno. Le premier transforme une mesure analogique en décision binaire. Le deuxième organise plusieurs sorties dans le temps. Le troisième relie directement l'état électrique d'un bouton à une LED, avec une résistance de rappel. Le dernier convertit la position d'un potentiomètre en angle de servomoteur.

Les programmes respectent les affectations imposées : A0 et D8 pour le seuil, D13-D12-D11 pour le feu, D2 et D7 pour le bouton, puis A0 et D9 pour le servo. Les temporisations du feu sont exactement de 3000 ms, 1000 ms et 3000 ms. La partie restante consiste à réaliser les montages Proteus, recueillir les preuves visuelles et compléter l'analyse avec les résultats réellement mesurés.
